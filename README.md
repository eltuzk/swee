# Swee

Swee is a site for learning software engineering fundamentals, aimed at students about to start an internship. It is bilingual: **English** (default and source language) and **Vietnamese**.

Current stage: static site (Astro + Starlight), no backend, not deployed. Lesson content is written and verified separately, so the lessons in this repo are only stubs for now.

## Running locally

Requires Node.js ≥ 22.23.4 (CI uses Node 24). All frontend commands run inside `frontend/`:

```bash
cd frontend
npm install
npm run dev        # http://localhost:4321  (English at /, Vietnamese at /vi/)
```

Other commands (inside `frontend/`):

| Command              | What it does                                                              |
| -------------------- | ------------------------------------------------------------------------- |
| `npm run build`      | Build the static site into `frontend/dist/` (including the Pagefind index) |
| `npm run preview`    | Preview the build                                                         |
| `npm run format`     | Format code with Prettier                                                 |
| `npm run check:i18n` | List lessons missing a Vietnamese version or with mismatched verification |

Environment variables: copy `frontend/.env.example` to `frontend/.env`. The only variable is `PUBLIC_API_URL`, left empty since there is no backend yet.

## Adding a lesson

1. Copy `frontend/src/content/docs/_template.mdx` into the group directory and name it after the slug, e.g. `caching/cache-invalidation.mdx`.
2. In the frontmatter: update `title`, `description`, `sources`, `prerequisites`; **remove** `sidebar.hidden` and `pagefind: false` (those two lines only hide the template page). Add `sidebar.order` if you need a specific order within the group.
3. Replace every `[TODO: ...]` with real content and drop components you don't use.
4. Keep `verification: unverified` until the lesson has been verified.

New lessons show up in the sidebar automatically (each group is autogenerated from its directory). To add a new **group**, create the directory and add one entry to the `groups` array in `frontend/astro.config.mjs` (English label + Vietnamese label).

Lessons are written in English first: a lesson that exists only under `vi/` has no English source and does not appear on the site.

### Adding the Vietnamese translation

1. Copy `frontend/src/content/docs/vi/_template.mdx` to the **same path** under `vi/`, e.g. `vi/caching/cache-invalidation.mdx`. The slug must match the English version, otherwise the language switcher won't land on the right lesson.
2. Set `locale="vi"` on `<TrueFalseQuiz>`.
3. Set `verification: unverified`: each translation has its own status and must be verified too.
4. Run `npm run check:i18n` to make sure nothing is missing or mismatched.

If there is no Vietnamese version yet, Starlight serves the English page at `/vi/...` with an "untranslated" notice, and the badge on that page states that the status belongs to the English version. **Don't leave raw machine translations in place.**

### Swee-specific frontmatter

| Field           | Type       | Meaning                                                              |
| --------------- | ---------- | -------------------------------------------------------------------- |
| `verification`  | see below  | Verification status of **this language version only**                |
| `sources`       | `string[]` | Links to official documentation backing the lesson                   |
| `prerequisites` | `string[]` | Slugs of lessons worth reading first (optional), e.g. `caching/redis` |

### `verification` statuses

| Value            | Badge (en / vi)                       | Meaning                                                                                     |
| ---------------- | ------------------------------------- | ------------------------------------------------------------------------------------------- |
| `unverified`     | Unverified / Chưa kiểm chứng          | Default. Newly written or translated, not yet checked against sources.                      |
| `claude-checked` | Checked by Claude / Claude đã rà soát | Each claim has been checked by Claude against official documentation; no human review yet. |
| `approved`       | Approved / Đã duyệt                   | The maintainer has read and approved the content.                                           |

When editing an `approved` lesson, downgrade it to `unverified` or `claude-checked` until it is approved again.

## Reporting incorrect content

Open an issue using the **Báo sai nội dung** (report incorrect content) template: which lesson, which language, which sentence, why it is wrong, and a source.
